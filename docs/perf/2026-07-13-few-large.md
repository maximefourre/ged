20 – 100 MB (~6 GB total), async.

## Conditions

- Command: `bin/perf-upload --profile few-large --mode async` (6 upload threads)
- Stack: isolated worktree Docker stack, production Rails env, Solid Queue in
  Puma (`JOB_CONCURRENCY=1`, 3 worker threads), Thruster in front

## Reading

- A 60 MB-average upload costs ~440 ms p50 on the 202 path — dominated by
  receiving the bytes and the staging-file write; no size limit was hit
  (none is configured).
- The single worker moves large payloads staging → Active Storage at roughly
  280 MB/s on this host; disk bandwidth, not CPU, is the relevant resource.
- Zero errors, all 100 requests completed, API count matches. Note: loopback
  networking — WAN clients would see upload latency dominated by their own
  bandwidth, not by GED.
